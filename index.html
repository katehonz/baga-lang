01 Езикът

Твърдението е част от кода. Проверката — от компилатора.

Бага не добавя верификация като външен инструмент. spec, ефектите и регионите са в езика, а компилаторът отказва да пусне програма, която им противоречи.

01 / SPEC

Договорът е код

spec описва входа, изхода, requires, ensures и decreases. Верификаторът доказва, оборва с контрапример или казва „не мога да реша“ — никога „изглежда наред“.

02 / EFFECTS

Ефектите са в типа

str !IO !NotFound е различен тип от str. ? ги разпространява, catch ги обработва. Забравен ефект не се компилира.

03 / MEMORY

Паметта има протокол

Световете са региони със собственост, замразяване и преместване. Компилаторът хваща висящите указатели, преди да станат production инцидент.

examples/effects.baga 
// Декларираме ефекти в return типа
fn прочети_файл(път: str) -> str !IO !NotFound {
    return "съдържание"
}

fn обработи(път: str) -> str !IO !NotFound {
    // ? propagate-ва ефектите нагоре
    let данни = прочети_файл(път)?
    return данни
}

fn main() {
    // catch обработва ВСЯКО измерение
    let резултат = прочети_файл("данни.txt")
        catch !NotFound => "празно"
        catch !IO => "грешка"
    print(резултат)
}
$./baga -I . -I app-product examples/effects.baga

fn фибоначи(n: i64) -> i64 {
    let mut a: i64 = 0
    let mut b: i64 = 1
    let mut i: i64 = 0
    while i < n {
        let temp = b
        b = a + b
        a = temp
        i = i + 1
    }
    return a
}

fn main() {

    }
}

02 Памет

Цял граф от данни — една стойност.

План-кеш, snapshot, документ, статистика: структури, които се раждат, замразяват, споделят и умират наведнъж. Световете превръщат този жизнен цикъл в стойност с проверен протокол — в C и в LLVM бекенда.

mutableсобственик
→world_freeze
frozenN читатели
→chan_send
movedдруга нишка
world_free(w) — освобождава цялата верига наведнъж; всеки достъп след това е ОБРОЧЕНО.
  • Протоколът е заключение, не конвенция. use-after-free, mutate-after-freeze, use-after-move и double-free се оборват с конкретен контрапример.
  • Замразеният свят е споделена read-only capability. N читатели без копиране; chan_send го мести към друга нишка.
  • dump/load без fixup. Корените и схемата са в региона, офсетите са позиционни. Компактен dump: 1.60 MB вместо 4.19 MB за същия свят.
  • Seatbelt срещу висящи указатели. Заемана стойност, изтекла във Vec/Map, е compile error — също през fn граница, generics, vec_slice/vec_concat и map_keys.
~3 nsдостъп през кеша
~5.7 nsstreaming достъп
~0.5 nsчист Vec без проверки

W2.14, същата машина. Регионът не е безплатен: таксата е няколко наносекунди на достъп и е документирана в docs/worlds-bg.md §4–5.

examples/worlds.baga 
// Регионът се пълни, замразява, дампи, освобождава
// и зарежда отново: офсетите са позиционни.
fn main() {
    let w = world_new()
    let v = wvec_new(w)
    wvec_push_str(w, v, "hello")
    wvec_push_str(w, v, "world")
    world_freeze(w)
    print(wvec_get_str(w, v, 0))
    print(wvec_get_str(w, v, 1))

    let dump = world_dump(w)
    world_free(w)

    let w2 = world_load(dump)
    let v2 = wvec_new(w2)
    wvec_push_str(w2, v2, "reloaded")
    print(wvec_get_str(w2, v2, 0))
    world_free(w2)
}

03 Доказателство

Три възможни отговора. Нито един не е „сигурно е“.

Верификаторът е малък и умишлено честен: извън доказания фрагмент казва НЕ МОГА ДА РЕША. Това е разликата между доказателство и надежда.

ДОКАЗАНО

Твърдението е изпълнено за всички входове във фрагмента. Терминацията се доказва с decreases.

ОБРОЧЕНО

Има вход, за който твърдението е лъжа. Верификаторът връща конкретен контрапример, не обвинение.

НЕ МОГА ДА РЕША

Извън доказания фрагмент. Честното „не знам“ е по-добро от фалшиво „доказано“.

abs_val.baga
spec abs_val {
    input:
        x: i64
    output: i64
    ensures:
        output >= 0
}

fn abs_val(x: i64) -> i64 {
    if x < 0 {
        return 0 - x
    }
    return x
}
реален изход · ./baga --verify abs_val.baga
verify abs_val:
  ensures #1 (output >= 0): ДОКАЗАНО
  аритметика (преливане: (0 - x)): ОБРОЧЕНО
    контрапример: x = -9223372036854775808
  (аритметика: 0/1 операции доказано безопасни — вердиктите за ensures са в идеализирания ℤ модел)
  ефект !Overflow: прелива при x = -9223372036854775808, а !Overflow не е деклариран

Обещанието е доказано за всички x. Но 0 - x прелива при INT64_MIN — и верификаторът не го скрива: това е отделен вердикт с конкретен контрапример. M31 индукция и M32 CDCL са в CI заедно със 138/138 gate-а; --json дава същите вердикти на агенти.

04 Измерено

Числата идват с командата, която ги е произвела.

rocksbaga — издръжлив LSM KV на чист Бага — срещу официалния RocksDB: едни и същи ключове, стойности и брой операции, на реален диск. Това е скоростен бар под конкретен harness, не feature-паритет.

Durable: fsync на всеки PUT. Batch: bulk load. Един писател, чист двигател, без RESP/TCP. Batch PUT е 82% в този прогон — числата трептят; затова командата и суровите артефакти са в scorecard-а.

Световете в продукция

  • boilaDB — SQL/HTTP/PG статистика в замразен свят; горещият път не взима глобален mutex.
  • fmrbaga · metbaga · cloudbaga — /metrics gauges в замразен свят през WMet.
  • queuebaga — read-through wcache за терминални статуси, дискът остава source of truth.
  • Не всичко иска свят — rocksbaga, raftbaga и txnbaga държат състоянието под собствена синхронизация; картата обяснява защо.

docs/app-worlds-bg.md — картата „къде световете помагат и къде не“.

05 Стек

Езикът се проверява от собствената си екосистема.

Всеки пакет е истински продукт, не демо: строи се със sandak, пуска се в CI и упражнява езика — IO, конкурентност, памет.

06 Старт

От клонирането до първия контрапример.

Няма външни библиотеки: нужни са C компилатор и make. LLVM бекендът е опция; make self проверява, че компилаторът компилира себе си до неподвижна точка.

терминал 
# клонирай и компилирай
git clone https://github.com/katehonz/baga-lang.git
cd baga-lang
make && make sandak

# първа програма
./baga -I . -I app-product examples/zdravei.baga
# Здравей, багатуре. Боят започва.

# интерактивна обвивка
make repl

# първият контрапример
./baga -I . -I app-product --verify examples/verify/abs_val.baga
