# Бага ⚔️

Език за програмиране за ерата на AI. Spec-first верификация. Ефекти като измерения на типа. Автоматично извлечени доказателства.

## Бърз старт

```bash
make
./baga examples/zdravei.baga
# Здравей, багатуре. Боят започва.
```

Нула зависимости. Трябва ти само `gcc` (или `clang`) и `make`.

## Какво е Бага

Бага е език, в който:

- **Спецификацията е първокласен гражданин.** `spec` е keyword. Компилаторът проверява имплементацията срещу спецификацията. AI пише кода, човекът пише spec-а, компилаторът е съдията.

- **Грешката е измерение, не изключение.** `String !IO !NotFound` е различен тип от `String`. Ефектите се събират автоматично при композиция.

- **Доказателствата се извличат, не се пишат.** Компилаторът генерира четими теореми от кода. Не Coq. Не Lean. Нормален текст.

Виж [CONCEPT.md](CONCEPT.md) за пълната концепция.

## Пример

```baga
fn main() {
    print("Здравей, багатуре. Боят започва.")
}
```

```baga
fn факториел(n: i64) -> i64 {
    if n <= 1 {
        return 1
    }
    n * факториел(n - 1)
}

fn main() {
    let x = факториел(10)
    print(x)
}
```
