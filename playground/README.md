# Baga Playground ⚔️

Браузър playground за езика — редактор, примери, и четирите режима на
компилатора (`run`, `--verify`, `--verify --json`, `--proofs`).

## Стартиране

```bash
make                       # изгради ./baga в корена, ако още не е
python3 playground/serve.py        # → http://localhost:8080
python3 playground/serve.py 9000   # друг порт
```

Само python3 stdlib — нула зависимости, както и компилаторът.

## Сигурност

Режимът `run` компилира и **изпълнява** кода, който получи. За локална
употреба и демо е ОК. Ако го хостваш публично, сложи го зад sandbox —
контейнер без мрежа, с `ulimit` за CPU/памет. Ограниченията в кода: 64 KB
вход, 10 s timeout на заявка, слуша само на `127.0.0.1`.
