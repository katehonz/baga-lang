## Граници, финални по дизайн (кандидати за „замразяване" в v1.0)

Документирани честно; да не се пипат:

- MEM-1 договорът за алиасинг: checker-ът следи променливи, не heap графи;
  `let y = x; drop(x); use(y)` не се диагностицира (`docs/language-bg.md:1008`).
- Алиаси през контейнери (`vec_push(v2, x)`) са недоловими (MEM-1 договор).
- Няма GC / borrow checker / lifetimes / linear types; цикли текат — няма weak
  refs (двата бекенда) (`docs/memory-rc-bg.md:47-58,311`).
- Runtime free-list: блокове > 1024 B не се reclaim-ват (pow2 класове до
  32 MiB компенсират частично); исторически боклук от `vec_grow`/`map_rehash`
  не се следи (`docs/language-bg.md:1016-1018`).
- Immortal escape handle-и `map_h`/`str_h`/`bytes_h` никога не release-ват
  (leak-safe по дизайн) (`docs/memory-rc-bg.md:274-281`).
- LLVM изключения по дизайн: без масиви/референции; `mem_mark/rewind/persist`
  само C бекенда; `persist` не се поддържа; `map_h`/`h_map` C-only; page guard
  вместо arena range guard в `baga_rc_hdr` (`docs/language-bg.md:1032-1034`).
- Verify методологията: честен skip извън фрагмента, никога фалшиво ДОКАЗАНО;
  fn-стойности непрозрачни за верификатора; частична коректност без терминация;
  проза-гаранции извън фрагмента (`docs/language-bg.md:911-912,1307-1316`).
- Self-host = доказателство за коректност, не продукция: 5–10× по-бавен, без
  ефектен/trait checker (`docs/compiler-bg.md:528-534`).
- Дребни: enum имената са глобални (`src/checker.c:3838`); `vec_slice` clamp-ва
  вместо грешка; `str_of_bytes` отрязва до първия NUL; няма имплицитни
  i64↔f64 конверсии; f64 не е Map ключ.

## Временни граници — решение преди v1.0 (затвори или roadmap-ни)

1. **LLVM `--rc` изключения** (`docs/language-bg.md:1024-1034`,
   план `docs/superpowers/plans/2026-08-21-llvm-rc-parity.md` ги класифицира
   като отложени, не отказани):
   - statement-ниво temp-ове не се release-ват („RC4 е C-only засега");
   - match scrutinee temp-ове не се release-ват;
   - closure captures не се retain-ват;
   - raise пътят не release-ва локали (leak при изход през ефект).
2. **Generics ръбове**: generic fn като стойност (`src/checker.c:2356`);
   `--rc` helper-и за heap полета на generic struct (M24); `Vec<Vec<T>>` с
   типова променлива (leak-safe); ламбди в generic тяло; spec върху generic.
3. ~~**Стари TODO-та**~~ ✅ — `src/proofs.c` `is_recursive` (мъртва
   евристика) е изтрит; `src/checker.c:2513` NODE_INDEX TODO-то е заменено с
   честен коментар (`x[i]` = суров C subscript примитив, елементен тип не се
   следи).
4. **std/net TLS сървър** — има само TLS 1.3 клиент; boilaDB отговаря `'N'`
   на SSLRequest.
5. **Self покритие извън PARITY_LIST**: C1 сигнали, drop/MEM-1, mem_*,
   `str_h`/`map_h` cast-ове, struct със sum-enum поле, generic fn от generic fn.
6. **Verify отворени проблеми** (не са v1 блокери, но да са видими в roadmap):
   channel liveness, пълен bitvector, богати полиноми
   (`docs/thesis-open-problems.md`).
