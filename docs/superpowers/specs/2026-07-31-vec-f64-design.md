# `Vec<f64>` — елементи с плаваща запетая (M6) — Дизайн

> Дата: 2026-07-31. Статус: одобрен (auto mode). Разширява елементните типове
> на Vec от i64/str към **i64/str/f64**, през всички backend-и (C, LLVM, self).
> Проблем: Vec елементите са ограничени до i64/str (checker-ът отказва f64);
> `Vec<f64>` / `vec_push(v, 1.5)` → грешка „неподдържан елементен тип f64".

## Идея

```baga
fn main() {
    let v = vec_new()
    vec_push(v, 1.5)
    vec_push(v, 2.5)
    print(vec_get(v, 0))   // 1.5 (f64)
}
```

Елементният тип се фиксира при първия push (i64/str/**f64**); смесване → грешка.

## Семантика

- **Съхранение:** vec-ът пази `void*` елементи. f64 (double, 8 байта = pointer
  на 64-bit) се bitcast-ва към/от `void*` (C: union type-pun; LLVM:
  double↔i64↔ptr).
- **C checker:** `resolve_type_node` Vec и `vec_push` — разрешават и `TYPE_F64`
  (съобщенията: „поддържат се i64, str и f64"). `vec_get` връща `vt->elem`
  (вече работи за f64 щом elem е f64).
- **C codegen:** избор на helper — elem str→`_str`, f64→`_f64`, иначе→`_i64`.
- **C runtime:** `baga_vec_push_f64`/`get_f64`/`set_f64` (union double↔void*).
- **LLVM:** `build_baga_vec_push_f64`/`get_f64`/`set_f64` (double→i64→ptr /
  ptr→i64→double); избор elem str/f64/i64; dispatch + builtin map.
- **Self компилатор:**
  - runtime `baga_vec_*_f64` (union).
  - `vec_is_f64(name)` (vec има f64 push); избор на helper в emit_expr:
    str→`_str`, f64→`_f64`, иначе→`_i64`.
  - **обобщена vec-mixing проверка** (3 типа): за всеки vec — елементният тип от
    първия push; различен по-късен push → грешка (вместо досегашното binary
    str/i64).
  - `expr_is_str`/`expr_typekind` — f64 литерал/call вече се разпознава (M4b).

## Извън обхвата

- `Vec<struct>` / `Vec<bool>` / `Vec<Vec>` (структурите не се побират в void*).
- Generic функции `fn f<T>`.

## Приемливост

- `vec_f64.baga`: baga ≡ baga2 ≡ LLVM (print на f64 елементи).
- Смесване i64+f64 → грешка (и в baga, и в baga2).
- Оракул 17/17 (с vec_f64); `make self` fixed point; `make test` зелен;
  нормален режим 19/19 без регресия.
