# Типизирани вектори `Vec<T>` — Имплементационен план

> **For agentic workers:** Steps use checkbox (`- [ ]`) syntax.
> **ВАЖНО:** БЕЗ `git commit`/`git add`.

**Goal:** `Vec` носи елементен тип; единни `vec_push`/`vec_get`/`vec_set` за i64 и str; смесването на типове е compile-time грешка; `_str` псевдонимите продължават да работят.

**Spec:** `docs/superpowers/specs/2026-07-31-typed-vec-design.md` (прочети я — съдържа семантиката и приемливостта).

**Ключови файлове за четене преди работа:** `src/checker.c` (`infer_call` с builtins таблицата, `type_str`, `type_eq`, NODE_LET обработката — провери дали env пази същия `Type*` указател, за да се разпространи фиксирането на `elem`), `src/codegen_c.c` (vec builtin емисия — търси `vec_push`), `src/codegen_llvm.c` (builtin map таблицата в NODE_CALL), `include/baga.h` (`struct Type` — полето `elem` вече съществува за TYPE_ARRAY; преизползва се за TYPE_VEC).

## Global Constraints

- Грешките на български, съществуващ стил. Наблюдаемото поведение на стария `_str` API непроменено. Оракулът (`tests/llvm_oracle.sh`) — зелен. Без git мутации.
- Елементни типове: `i64` (i32 се приема като i64) и `str`. `f64`/други → грешка.
- Елементният тип се фиксира чрез МУТАЦИЯ на `Type->elem` на типа, съхранен в env за съответното свързване — затова провери, че env пази указател, не копие.

**Interfaces:**

- [ ] **Step 3: Специална обработка в infer_call**

Махни vec записите от статичната builtins таблица. В `infer_call`, в клона за NODE_IDENT callee, ПРЕДИ таблицата (или след нея — но преди user-function lookup), добави vec обработка. Аргументите вече са инферирани (цикълът в началото на infer_call) — ползвай `n->args.data[i]->type`.

```c
        /* типизирани вектори: Vec<T> */
        if (strcmp(name, "vec_new") == 0) {
            n->callee->type = type_new(TYPE_VOID);
            return type_new(TYPE_VEC);      /* elem = NULL: неизвестен */
        }
        if (strcmp(name, "vec_push") == 0 || strcmp(name, "vec_set") == 0 ||
            strcmp(name, "vec_push_str") == 0 || strcmp(name, "vec_set_str") == 0) {
            int is_str_alias = (strstr(name, "_str") != NULL);
            int xidx = (strstr(name, "set") != NULL) ? 2 : 1;   /* индекс на елемента */
            n->callee->type = type_new(TYPE_VOID);
            if (n->args.len != xidx + 1) {
                check_error(ctx, n->pos, "'%s' очаква %d аргумента, получих %d",
                            name, xidx + 1, n->args.len);
                return type_new(TYPE_ERROR);
            }
            Type *vt = n->args.data[0]->type;
            if (!vt || vt->kind != TYPE_VEC) {
                check_error(ctx, n->pos, "'%s' върху не-вектор (%s)", name, type_str(vt));
                return type_new(TYPE_ERROR);
            }
            Type *xt = is_str_alias ? type_new(TYPE_STR) : n->args.data[xidx]->type;
            if (is_str_alias && !vt->elem) vt->elem = type_new(TYPE_STR);
            if (xt->kind == TYPE_I32) xt = type_new(TYPE_I64);
            if (!is_str_alias && xt->kind != TYPE_I64 && xt->kind != TYPE_STR) {
                check_error(ctx, n->pos,
                    "%s: неподдържан елементен тип %s за Vec (поддържат се i64 и str)",
                    name, type_str(xt));
                return type_new(TYPE_ERROR);
            }
            if (!vt->elem) {
                vt->elem = xt;
            } else if (vt->elem->kind != xt->kind) {
                check_error(ctx, n->pos, "%s: елемент от тип %s, но векторът е %s",
                            name, type_str(xt), type_str(vt));
            }
            return type_new(TYPE_VOID);
        }
        if (strcmp(name, "vec_get") == 0 || strcmp(name, "vec_get_str") == 0) {
            int is_str_alias = (strstr(name, "_str") != NULL);
            n->callee->type = type_new(TYPE_VOID);
            Type *vt = n->args.len > 0 ? n->args.data[0]->type : NULL;
            if (is_str_alias) {
                if (vt && vt->kind == TYPE_VEC && !vt->elem) vt->elem = type_new(TYPE_STR);
                return type_new(TYPE_STR);
            }
            if (vt && vt->kind == TYPE_VEC && vt->elem) return vt->elem;
            if (vt && vt->kind == TYPE_VEC)
                check_error(ctx, n->pos,
                    "vec_get: типът на вектора не е известен — извикай vec_push първо");
            return type_new(TYPE_ERROR);
        }
        if (strcmp(name, "vec_len") == 0) {
            n->callee->type = type_new(TYPE_VOID);
            return type_new(TYPE_I64);
        }
```

(Кодът е ориентировъчен — съобрази имената/стила с реалния checker. `vec_len` махни и от таблицата, за да е на едно място; или го остави в таблицата — единственото изискване е vec_push/get/set и псевдонимите да са извън нея.)

### Task 2: Codegen C + LLVM — helper по елементния тип

**Files:** Modify `src/codegen_c.c`, `src/codegen_llvm.c`
