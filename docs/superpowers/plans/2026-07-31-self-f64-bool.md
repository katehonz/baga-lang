### Task 1: Tokenizer + parser (float/bool възли)

**Files:** Modify `self/compiler.baga`

- [ ] **Step 1: tokenizer float (kind 102)**

В digit-клона (`if is_digit(c) == 1`), след консумирането на цифрите, добави:
ако `pos+1 < n` и `char_at(src,pos)==46` (`.`) и `is_digit(char_at(src,pos+1))`
→ `is_float=1`, консумирай `.` и дробните цифри. Emit-вай kind `102` за float,
иначе `100` (int). Текстът е целият литерал (`substr(src, start, pos)`).

- [ ] **Step 2: parse_primary**

Добави `if k == 102 { advance; return ast_kind(nk, nt, fc, ns, 19, t) }`
(float lit, kind 19). Промени `true`/`false`:
`if k == 14 { advance; return ast_kind(..., 20, "1") }`,
`if k == 15 { advance; return ast_kind(..., 20, "0") }`
(bool lit, kind 20 — досега бяха kind 0).

- [ ] **Step 3: Проверка** — `make && ./baga --emit-c self/compiler.baga
  > /tmp/s2.c && gcc -O2 -Iinclude /tmp/s2.c -o /tmp/baga2 -lm` → компилира се
  (промяната е в self компилатора; baga го компилира).

### Task 2: Codegen — emit, евристики, print, let

**Files:** Modify `self/compiler.baga`

- [ ] **Step 1: emit_expr**

До `if k == 0 { return concat(t, "LL") }` добави:
`if k == 19 { return t }` (float лит. суров) и `if k == 20 { return t }`
(bool лит. `1`/`0`).

- [ ] **Step 2: `expr_is_float`** (нова fn, модел `expr_is_str`)

float lit (19) → 1; binary (3) → 1 ако ляв/десен е float; call (4) → 1 ако
`fn_ret_c_type(...) == "double"`; ident (2) → проследи до let-инита, рекурсира.

- [ ] **Step 3: `expr_is_bool`** (нова fn)

bool lit (20) → 1; binary (3) с op в `== != < > <= >= && ||` → 1; call (4) →
1 за `str_eq` или user fn с `fn_ret_c_type == "int"`; ident (2) → проследи,
рекурсира.

- [ ] **Step 4: print (EXPR_STMT, k==10)**

Разшири if-а: `expr_is_str` → `%s`; иначе `expr_is_float` → `printf("%g\n", arg)`;
иначе `expr_is_bool` → `printf("%s\n", (arg) ? "true" : "false")`; иначе `%lld`.

- [ ] **Step 5: LET ctype (k==6)**

След съществуващите проверки добави:
`if expr_is_float(nk, nt, fc, ns, prog, init) == 1 { ctype = "double" }`.

- [ ] **Step 6: Проверка**

`make && ./baga --emit-c self/compiler.baga > /tmp/s2.c && gcc … -o /tmp/baga2`
`/tmp/baga2 examples/types.baga > /tmp/t.c && gcc … -o /tmp/t && /tmp/t`
→ `78.5398 / true / 13.5 / true` (идентично с `./baga examples/types.baga`).

## Self-Review бележки

- Coverage: precision fix (T0), tokenizer/parser (T1), codegen+евристики (T2),
  регресия/docs (T3).
- Тънки места: (1) `%.17g` round-trip — C и LLVM трябва да се сменят ЗАЕДНО,
  иначе оракулът се чупи; (2) float tokenizer guard „`.` + цифра" пази
  `0..10` range-овете; (3) bool като kind 20 emit-ва `1`/`0` — if/while
  условията не минават през print, та не се влияят; (4) LET ctype double е
  критичен (иначе `int64_t r = 5.0` орязва); (5) expr_is_float/bool ident-trace
  дублира expr_is_str (house style) — провери рекурсията да не е безкрайна
  (проследяването стига до let-инит, не цикли); (6) fixed point-ът:
  compiler.baga ползва сравнения/bool, но само в if-условия (не print) —
  промяната на bool представянето не мени генерирания C за тях.
