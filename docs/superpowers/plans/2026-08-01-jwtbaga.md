# jwtbaga Implementation Plan

**Goal:** A pure JWT HS256 signer/verifier (`app-product/jwtbaga/jwt.baga`)
over `std/` (crypto/hmac, crypto/ct, bytes, json, str), a golden-vector test, a
demo HTTP server that is the first consumer of `httpdbaga/http.baga`, and a
`gaps.md` logging language friction.

**Spec:** `docs/superpowers/specs/2026-08-01-jwtbaga-design.md`

## Global Constraints

- **No compiler changes.** Gaps logged in `gaps.md`.
- All comments/READMEs/docs in English.
- `str` cannot hold null bytes ⇒ signatures stay `Vec<i64>`; verify via
  `ct_eq_bytes`. `concat` is 2-arg. `json_escape` returns a quoted+escaped
  string. `json_get` returns -1 when absent (guard before `json_serialize`).
- Every task ends green.

## Task 1 — `jwt.baga`: base64url + sign/verify

- [ ] Imports (hmac, ct, bytes, str). Header comment (pure, HS256 only).
- [ ] `base64url_encode(b)`: `base64_encode` then drop trailing `=`.
- [ ] `base64url_decode(s)`: map `-`→`+`, `_`→`/`, re-pad to multiple of 4 with
      `=`, then `base64_decode`.
- [ ] `jwt_sign(key, msg) -> str` = `base64url_encode(hmac_sha256(key, msg))`.
- [ ] `jwt_verify(key, msg, sig) -> bool` = `ct_eq_bytes(base64url_decode(sig),
      hmac_sha256(key, msg))`.
- **Verify:** compiles via the test (Task 3) — no `main` in the lib.

## Task 2 — `jwt.baga`: encode/decode/claim

- [ ] `jwt_encode(key, payload_json)`: fixed header
      `{"alg":"HS256","typ":"JWT"}`; `h = b64url(header)`, `p = b64url(payload)`;
      `sig = jwt_sign(key, h + "." + p)`; return `h.p.sig`.
- [ ] `jwt_decode(key, token)`: split on `.`; require exactly 3; `jwt_verify`
      over `p0.p1`; on success `bytes_to_str(base64url_decode(p1))` else `""`.
      (bytes→str is safe: JSON payload text has no null bytes.)
- [ ] Internal `bytes_to_str(b)` (chr per byte) — note G5 in gaps.
- [ ] `jwt_claim(token, name)`: decode payload part (no sig check), `json_parse`,
      guard `json_get != -1`, return `json_serialize` of the node, else `""`.
- **Verify:** compiles via test.

## Task 3 — `tests/jwt_test.baga` (test-first consumer)

- [ ] `check(name, ok)` helper (exit 1 on FAIL).
- [ ] Cases: base64url alphabet (`-_-_`) + null-byte round-trip; **golden

- **Verify:** `./baga tests/jwt_test.baga` prints `jwt_test: all passed`.

## Task 4 — Demo server + README

      secret `env("JWT_SECRET")`/`baga-secret`. Routes: `GET /token?sub=NAME`,
