# MEM-1/2 — drop + checker-enforced memory discipline Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `drop(x)` with checker-enforced live/dropped tracking (use-after-drop and double-drop are compile errors) + real reclaim via a size-classed free list in the bump arena + MEM-2 verifier obligations (REFUTED use-after-drop with witness).

**Architecture:** New builtin `drop` special-cased in `infer_call`; per-env-entry state flags (`dropped`/`is_param`/`captured`/`scope_depth`) drive the seatbelt; runtime free list (16 B classes ≤ 1024 B) inside the emitted `baga_alloc` section; deep `baga_drop_*` walkers emitted in the C runtime; verifier gets an `HK_DROP` handle kind reusing M14's kind-3 violation path.

**Tech Stack:** Baga compiler (`src/checker.c`, `src/codegen_c.c`, `src/verify.c`), tests via `scripts/baga-test` + grep probes + `examples/verify/`.

**Spec:** `docs/superpowers/specs/2026-08-05-mem-drop-design.md`

- [ ] **Step 1: free list in the emitted `baga_alloc` (`src/codegen_c.c:1721-1737`)**

Add before/inside the existing emitted text (keep the bump path and mutex):
```c
#define BAGA_FL_CLASSES 64   /* free list: 16-байтови класове ≤ 1024 B */
static void *baga_fl[BAGA_FL_CLASSES];

static void baga_free(void *p, int64_t n) {
    if (!p || n <= 0 || n > 1024) return;
    int c = (int)((n + 15) / 16) - 1;
    pthread_mutex_lock(&baga_alloc_mu);
    *(void **)p = baga_fl[c];
    baga_fl[c] = p;
    pthread_mutex_unlock(&baga_alloc_mu);
}
```
In `baga_alloc`, BEFORE the bump path: round `n` up to 16 (`rn = (n + 15) & ~(size_t)15`); if `rn <= 1024`, lock, pop `baga_fl[rn/16 - 1]` if non-NULL, unlock, return the popped block. Otherwise fall through to the existing bump code UNCHANGED (it keeps using the original `n`).

- [ ] **Step 2: drop walkers (emitted after the map helpers, ~:2095)**

```c
static void baga_drop_bytes(baga_bytes b) { baga_free(b.data, b.len); }

/* elem_kind: 0 = inline (i64/f64), 1 = str (споделени — не се пипат), 2 = box (bytes/struct) */
static void baga_drop_vec(baga_Vec *v, int elem_kind, int64_t elem_size) {
    if (!v) return;
    if (elem_kind == 2)
        for (int64_t i = 0; i < v->len; i++) baga_free(v->data[i], elem_size);
    baga_free(v->data, v->cap * 8);
    baga_free(v, (int64_t)sizeof(baga_Vec));
}

static void baga_drop_map(baga_Map *m, int val_is_box, int64_t val_size) {
    if (!m) return;
    for (int64_t i = 0; i < m->nb; i++)
        for (baga_MapEntry *e = m->b[i]; e; e = e->next) {
            if (val_is_box && e->pv) baga_free(e->pv, val_size);
            baga_free(e, (int64_t)sizeof(baga_MapEntry));
        }
    baga_free(m->b, m->nb * (int64_t)sizeof(baga_MapEntry *));
    baga_free(m, (int64_t)sizeof(baga_Map));
}

static void baga_drop_fn(int64_t h) { baga_cell2_free(h); }
```
Add `baga_cell2_free` next to `baga_cell2` (~:2131): read how cell2 packs the pair (malloc'd) and free it correctly. NOTE: bytes/struct element boxes are freed, but their INNER buffers (bytes.data, str fields) stay in the arena — shared ownership, documented. Env boxes of closures likewise stay.

- [ ] **Step 3: drop special-case rules (extend Task 1's block)**

After the type check: `EnvEntry *e = env_find(ctx, a->name);`
- `!e` → `drop: '%s' не е локална променлива`
- `e->dropped` → `повторен drop на '%s'`
- `e->is_param` → `drop на параметър '%s' — параметрите споделят буфера на извикващия`
- `e->captured` → `'%s' е заснет от ламбда — drop би оставил висящ указател`
- loop rule: if inside a loop body (see Step 5) and `e->scope_depth < ctx->loop_depth` → `drop на външна за цикъла променлива '%s' — втората итерация би била use-after-drop`
- else `e->dropped = 1;` AND append `e` to the current branch drop-log (Step 4).

- [ ] **Step 4: if/else join (NODE_IF :1270-1289)**

Add to CheckCtx: `EnvEntry *drop_log[256]; int n_drop_log;` Semantics around branch checking:
```c
int log_base = ctx->n_drop_log;
infer(ctx, n->then_br);
int then_end = ctx->n_drop_log;
/* else-клонът не трябва да вижда drop-овете от then: временно ги вдигни */
for (int i = log_base; i < then_end; i++) ctx->drop_log[i]->dropped = 0;
if (n->else_br) infer(ctx, n->else_br);
/* intersection: остават dropped само маркираните и в двата клона */
for (int i = log_base; i < then_end; i++) {
    EnvEntry *e = ctx->drop_log[i];
    int in_else = 0;
    for (int j = then_end; j < ctx->n_drop_log; j++)
        if (ctx->drop_log[j] == e) { in_else = 1; break; }
    if (in_else) e->dropped = 1;
}
ctx->n_drop_log = log_base;   /* слей нагоре: повторно маркираните се логват отново при по-външен if */
/* re-log the survivors so an OUTER if sees them */
for (int i = log_base; i < then_end; i++) if (ctx->drop_log[i]->dropped) { /* keep in log: shift handled by implementer — simplest: compact survivors into log_base.. */ }
```
(The implementer should simplify: compact the surviving entries into the log at log_base and set n_drop_log accordingly. If there's no else_br, restore all then-drops to 0 — nothing is definitely dropped.) Verify with the probes in Step 7. Watch memoization: `infer` on the same node twice is a no-op, and branches are checked exactly once, so the log reflects one pass.
