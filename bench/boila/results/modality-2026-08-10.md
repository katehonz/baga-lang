# boilaDB modality benches — S5 / G1 / V2 (2026-08-10)

Chunked multi-process seed (Q2 arena) via `bench/boila/run_modality_benches.sh`.
Sources: `ts_bench.baga`, `graph_bench.baga`, `vec_bench.baga`.

```bash
bash bench/boila/run_modality_benches.sh all   # defaults below
TS_BENCH_TOTAL=100000 bash bench/boila/run_modality_benches.sh ts
```

## S5 — time-series (`time_bucket` + range)

**Hash GROUP BY** (`Map<i64,i64>` for single numeric/`time_bucket`,
`Map<str,i64>` hex for multi/text; on-the-fly bucket — no full-table
rewrite). Secondary `CREATE INDEX pts_ts_ix ON pts (ts)` after table
create (unused by full-table GROUP BY; residual for ts-range plans).

| N points | GROUP BY 1m | range+bucket 1h | Gate &lt; 50 ms | vs linear (prior) |
|---|---|---|---|---|
| 10k | **36 ms** | **35 ms** | **OK** | was 39 / 31 ms |
| 20k | **81 ms** | **84 ms** | FAIL | was 98 / 66 ms |
| 100k | **441 ms** | **437 ms** | FAIL | was **1682** / 382 ms |

- **~3.8×** on 100k full-table `GROUP BY time_bucket` after Q-ghash.
- PLAN target **1M points &lt; 50 ms**: **not met** — scan+materialize
  dominates (~4.4 µs/row); hash lookup is no longer the bottleneck.
- Gate holds up to ~**10k points** on this host.
- Residual: stream agg without full row materialize; use secondary ts
  index for `WHERE ts …` ranges; optional pre-aggregated buckets.

## G1 — graph BFS d=3

| Chain edges (+skip = 2×) | BFS d=3 from 0 | Nodes visited | Gate &lt; 100 ms |
|---|---|---|---|
| 2k (+2k skip) | 39 µs | 9 | **OK** |
| 100k (+100k skip) | **42 µs** | 9 | **OK** |

- Topology: chain `i→i+1` + skip `i→i+3`; BFS depth 3 is local (~9 nodes).
- PLAN target **1M edges**: seed of 1M not run (wall ~1h+ at 100k seed
  rate); latency gate is **independent of total edges** for this
  shallow BFS (adjacency point lookups). Functional scale verified at
  **200k edges** written (100k chain + 100k skip).

## V2 — vector kNN (HNSW)

HNSW built **after seed** (last write chunk) so bulk INSERT avoids
per-row graph maintenance.

| N × dim | kNN L2 LIMIT 10 | Gate &lt; 20 ms |
|---|---|---|
| 400 × 8d | 5.4 ms | **OK** |
| **10k × 16d** | **1.7 ms** | **OK** |

- PLAN target **100k×128d recall@10 ≥ 0.95**: **not measured** — SQL
  vector literals for 128d are huge (Q2 arena + string build); seed at
  10k×16d is the practical bulk path today.
- Latency gate &lt; 20 ms: **pass** at 10k×16d (HNSW path).
- Recall@10 not scored (no brute-force oracle in bench; residual).

## How to re-run

```bash

bash bench/boila/run_modality_benches.sh all

# custom
TS_BENCH_TOTAL=10000 TS_BENCH_NCHUNKS=5 bash bench/boila/run_modality_benches.sh ts
GR_BENCH_TOTAL=50000 bash bench/boila/run_modality_benches.sh graph
VEC_BENCH_TOTAL=5000 VEC_BENCH_DIM=16 bash bench/boila/run_modality_benches.sh vec
```
