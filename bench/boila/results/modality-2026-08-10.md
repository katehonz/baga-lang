# boilaDB modality benches — S5 / G1 / V2 (2026-08-10)

Chunked multi-process seed (Q2 arena) via `bench/boila/run_modality_benches.sh`.
Sources: `ts_bench.baga`, `graph_bench.baga`, `vec_bench.baga`.

```bash
bash bench/boila/run_modality_benches.sh all   # defaults below
TS_BENCH_TOTAL=100000 bash bench/boila/run_modality_benches.sh ts
```

## S5 — time-series (`time_bucket` + range)

**Hash GROUP BY** + **K3h sorted prefix seek** (prefix scan rebuild sorts
keys; cache kept across warm queries; `boila_ix_range` lower_bound +
early-stop). Secondary `pts_ts_ix`; K3g exclusive half-open windows.

| N points | GROUP BY 1m | PK range+bucket 1h | ts-ix window 10k + bucket | Gate &lt; 50 ms |
|---|---|---|---|---|
| 10k | **16 ms** | **17 ms** | **18 ms** | **OK** |
| 20k | **34 ms** | **36 ms** | **21 ms** | **OK** |
| 100k | **167 ms** | **180 ms** | **45 ms** | FAIL (full); window ~OK |

- Full-table 100k: **167 ms** (was 1.68 s linear → 431 ms hash → 167 ms K3h).
- **ts-ix window last 10k @100k table: 45 ms** (was 283 ms pre-seek).
- Gate **&lt; 50 ms holds to ~20k** full-table; windowed path near gate at 100k.
- PLAN **1M &lt; 50 ms**: still not met for full scan (live_map of all keys).
- Residual: stream agg without full materialize; LSM range without full
  live fold; pre-agg buckets.

## G1 — graph BFS d=3

| Chain edges (+skip = 2×) | BFS d=3 from 0 | Nodes visited | Gate &lt; 100 ms |
|---|---|---|---|
| 2k (+2k skip) | 39 µs | 9 | **OK** |
| 100k (+100k skip) | **42 µs** | 9 | **OK** |

- Topology: chain `i→i+1` + skip `i→i+3`; BFS depth 3 is local (~9 nodes).
- PLAN target **1M edges**: seed of 1M not run (wall ~1h+ at 100k seed
  rate); latency gate is **independent of total edges** for this
  shallow BFS (adjacency point lookups). Functional scale verified at
  **200k edges** written (100k chain + 100k skip).

## V2 — vector kNN (HNSW)

HNSW built **after seed** (last write chunk) so bulk INSERT avoids
per-row graph maintenance.

| N × dim | kNN L2 LIMIT 10 | Gate &lt; 20 ms |
|---|---|---|
| 400 × 8d | 5.4 ms | **OK** |
| **10k × 16d** | **1.7 ms** | **OK** |

- PLAN target **100k×128d recall@10 ≥ 0.95**: **not measured** — SQL
  vector literals for 128d are huge (Q2 arena + string build); seed at
  10k×16d is the practical bulk path today.
- Latency gate &lt; 20 ms: **pass** at 10k×16d (HNSW path).
- Recall@10 not scored (no brute-force oracle in bench; residual).
