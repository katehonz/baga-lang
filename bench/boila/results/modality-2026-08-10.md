# boilaDB modality benches — S5 / G1 / V2 (2026-08-10)

Chunked multi-process seed (Q2 arena) via `bench/boila/run_modality_benches.sh`.
Sources: `ts_bench.baga`, `graph_bench.baga`, `vec_bench.baga`.

```bash
bash bench/boila/run_modality_benches.sh all   # defaults below
TS_BENCH_TOTAL=100000 bash bench/boila/run_modality_benches.sh ts
```

## S5 — time-series (`time_bucket` + range)

**K3j continuous ROLLUP** + hash GROUP BY + K3h/K3i prefix scan + stream
agg. Secondary `pts_ts_ix`; K3g exclusive half-open windows.
Bench creates `pts_1m` / `pts_1h` rollups (`CREATE ROLLUP … SUM(v)`).

| N points | GROUP BY 1m (rollup) | bucket 1h (rollup) | ts window 10k + bucket | Gate &lt; 50 ms |
|---|---|---|---|---|
| 10k | **~0.3 ms** | **~0.2 ms** | (raw ~19 ms) | **OK** |
| 20k | **~0.7 ms** | **~0.3 ms** | (raw ~22 ms) | **OK** |
| 100k | **~2.9 ms** | **~1.6 ms** | **~21 ms** (K3k) | **OK** |

- Full-table 100k via rollup: **~2.9 ms** (was 1.68 s → … → 174 ms GET
  path). O(buckets) scan of pre-agg cells, not N row GETs.
- **K3j:** `CREATE ROLLUP … USING time_bucket … SUM(v)` maintains
  count(*)+sum on DML; unfiltered GROUP BY → rollup cells.
- **K3k:** partial `WHERE ts` window = complete buckets via point GETs
  on rollup + tight secondary edge bands (raw). **@100k last-10k
  window ~21 ms** (was ~38 ms pure row path).
- Gate **&lt; 50 ms holds at 100k** for full + 1h + window.
- PLAN **1M**: rollup scales with **#buckets**; window cost ≈ edge
  ix rebuild + O(edge rows) + O(complete cells).
- Residual: stream join/xw; PK-range+bucket without rollup still
  GET-bound; share ix snapshot across edge calls (rebuild once).

## G1 — graph BFS d=3

| Chain edges (+skip = 2×) | BFS d=3 from 0 | Nodes visited | Gate &lt; 100 ms |
|---|---|---|---|
| 2k (+2k skip) | 39 µs | 9 | **OK** |
| 100k (+100k skip) | **42 µs** | 9 | **OK** |

- Topology: chain `i→i+1` + skip `i→i+3`; BFS depth 3 is local (~9 nodes).
- PLAN target **1M edges**: seed of 1M not run (wall ~1h+ at 100k seed
  rate); latency gate is **independent of total edges** for this
  shallow BFS (adjacency point lookups). Functional scale verified at
  **200k edges** written (100k chain + 100k skip).

## V2 — vector kNN (HNSW)

**Bulk seed** via `boila_put` + packed fixed-point vectors (no SQL
literals). HNSW built after last write chunk.

| N × dim | seed path | kNN L2 LIMIT 10 | Gate &lt; 20 ms |
|---|---|---|---|
| 10k × 16d | bulk put | **14 ms** | **OK** |
| **5k × 128d** | bulk put | **12 ms** | **OK** |
| 10k × 128d | bulk put | **~23 ms** | FAIL (near) |
| 50k × 32d | bulk put | 80 ms | FAIL |

- **V4b–e search:** L0 embed pay, adaptive ef, plan-cache **knn_pay**
  (parse query vector once), L2 from packed payload (no f64 repack).
- PLAN **100k×128d recall@10 ≥ 0.95**: not measured; **5k×128d OK**.
- 10k×128d residual **~22–23 ms** (storage GET bound; gate 20 ms).
- **Positioning:** multimodal SQL+HNSW, not a pure ANN product (cf.
  Qdrant/pgvector-at-scale for dedicated vector workloads).

## How to re-run

```bash
# defaults: ts 100k, graph 100k, vec 10k dim16
bash bench/boila/run_modality_benches.sh all

# custom
TS_BENCH_TOTAL=10000 TS_BENCH_NCHUNKS=5 bash bench/boila/run_modality_benches.sh ts
GR_BENCH_TOTAL=50000 bash bench/boila/run_modality_benches.sh graph
VEC_BENCH_TOTAL=5000 VEC_BENCH_DIM=128 bash bench/boila/run_modality_benches.sh vec
VEC_BENCH_TOTAL=10000 VEC_BENCH_DIM=128 bash bench/boila/run_modality_benches.sh vec
```
